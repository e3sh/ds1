## 📖 概要・コンセプト

『DS1ish』は、1984年の名作アクションパズルRPG『ドラゴンスレイヤー (Level 2.0)』へのリスペクト・オマージュとして個人開発された**非公式ファンメイドWebゲーム**です。

原作の魅力であるコアメカニクス（8方向移動・4方向体当たり戦闘、経験値が防御力とHP回復上限を兼ねる成長ルール、指輪による岩や我が家の倉庫番プッシュ、8歩周期の宝箱開錠、3首ドラゴン討伐と世界変化、魔法封印下での王冠4個運搬脱出）をベースにしつつ、**固定ステージマップの代わりにダンジョンマップをプロシージャル（自動）生成**とし、現代的なQoL機能や検証基盤を組み合わせています。

### 主な特徴

1. **ダンジョンマップのプロシージャル生成（全域9セクター動的配置 × 6種トポロジー）**:
   - 本作は固定のステージマップを持たず、プレイごとに **64×64 トーラス迷宮（上下左右がループする空間）** のマップ構造を自動生成します。
   - マップを不規則な9セクターに分割し、シードごとに「我が家」と「3首ドラゴン要塞」の配置セクターおよび地形トポロジー（`MULTI_SECTOR`, `STANDARD_ROOMS`, `PILLAR_GRID`, `NARROW_MAZE`, `SPIRAL_LABYRINTH`, `FORTRESS_ARENA`）を構成します。
   - マップ内部の壁はすべて破壊・移動可能なブロック（`BLOCK`）で構成され、生成直後にクリア可能性診断（初期導線・重複ゼロ・ドラゴン要塞クリアランス・期待到達STR試算）を行うことで詰みマップを防いでいます。
2. **攻防2軸（3×3マトリクス）の「敵相対タクティカル脅威度マーカー」**:
   - 刻々と変化するプレイヤーの攻撃力（`STR`・剣所持状態）と防御力（`EXP`・残り`HP`）を敵のステータスとリアルタイム比較し、足元に二重リングマーカー（外枠：倒しやすさ5段階 ／ 中心コア：被弾・即死リスク）を表示します。
   - 「一撃で倒せるが、先制されたら即死する敵（ガラスの剣）」や「剣を床に置いて鍵や石を持った瞬間に周囲の敵が一斉に危険壁へ反転する運搬パズル」を視覚的に把握できます（`[T]` キーでクラシックな黒シャドウ表示と切替可能）。
3. **バランスプリセット ＆ 4種のマップテーマ（アーキタイプ）**:
   - 「地形トポロジー（6種）× 難易度（`EASY / NORMAL / HARD`）× プレイ時間目安（`BLITZ: 約10分 / STANDARD: 約25分 / MARATHON: 約45分`）」に、原作の代表的な攻略戦術をモチーフにしたマップテーマ（`BALANCED`, `SANCTUARY: 十字架結界`, `WARP_NEXUS: ワープ迷宮`, `ARMORY: 複数剣配置`）を選択可能。
   - 気に入った生成マップのシードと設定は、**1行の共有コード（`DS1MAP:...`）** として保存・共有・再プレイが可能です。
4. **自律攻略AIボット (`AutoPlayBot`) ＆ ワンキー操作引き継ぎ**:
   - 序盤の装備回収、十字架・岩による墓封鎖、8歩周期開錠、指輪で我が家をドラゴン近傍へ押し運ぶ「拠点引越し戦術」、3首討伐、王冠4個脱出までを自動プレイするAIを搭載。
   - プレイ中にいつでも `[A]` または `[Tab]` キーで **手動操作 ⇔ AI自動プレイ（1x / 2x / 5x / 一時停止）** をシームレスに切り替え可能です。

## 🎮 操作方法

| キー / 操作 | 機能・アクション |
| :--- | :--- |
| **矢印キー / WASD / テンキー(1〜9)** | 移動・体当たり攻撃（EXP蓄積で斜め8方向移動が解禁） |
| **Space** | その場で待機 ／ 足元のアイテムを拾う・置く・交換 ／ 宝箱を開ける |
| **M / 数字キー (1〜9)** | 魔法の選択（JUMP, RETURN, MAP, BREAK, KICK, FREEZE, FLASH, FLY, SAVE） |
| **X / Enter** | 選択中の魔法を発動 |
| **T** | 敵相対タクティカルマーカー表示切替（`TACTICAL` ⇔ `RETRO`） |
| **I** | ダンジョン構造＆成長曲線インスペクタモーダル開閉 |
| **A / Tab** | AI自動プレイ（AutoPlayBot）の開始 ／ 手動操作への即時引き継ぎ |
| **Q** | ギブアップ確認モーダル |
| **Esc** | 全体マップ・モーダルを閉じる |

## 🛠 技術スタック

- **言語**: TypeScript 5.5+ (Strict mode, Node.js / Browser ヘッドレス分離設計)
- **ビルドツール**: Vite 5.4+
- **描画・音響**: HTML5 2D Canvas + DOM HUD + Web Audio API (PSG矩形波・ノイズ合成)
- **テスト・検証**: `tsx` による自動テストスイート（全35スイート）＆ ヘッドレスAIバッチシミュレータ

## 🚀 開発・起動手順

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 開発用ローカルサーバーの起動
```bash
npm run dev
```
起動後、ブラウザでターミナルに表示されたURL（通常は `http://localhost:3000`）を開いてください。

### 3. プロダクションビルド
```bash
npm run build
```
`dist/` フォルダに静的ファイルが出力されます。

### 4. 自動テストの実行
```bash
npm test
```

### 5. ヘッドレスAIバッチシミュレーション・パラメータ評価
描画を介さず Node.js 上で `AutoPlayBot` を高速実行し、クリア率・ターン数・成長曲線・死因統計などのKPIレポートを出力します。
```bash
# 標準設定でのバッチシミュレーション実行
npm run simulate

# トポロジーや試行回数・最大ターン数を指定して実行
npm run simulate -- --runs=20 --turns=3000 --topology=MULTI_SECTOR --difficulty=NORMAL --pacing=STANDARD

# 複数ボット戦略の比較評価スクリプト実行
npm run evaluate
```

## 📁 ディレクトリ構成

- `src/` : ゲーム本体のソースコード
  - `core/` : ゲームエンジン、イベントバス、決定論的乱数（`SeedRandom`）、サブコントローラー群（`engine/`）
  - `models/` : プレイヤー、敵、3首ドラゴン、ゴースト、64×64多層ワールドマップモデル
  - `systems/` : 戦闘、移動、敵AI、ゴーストAI、魔法、宝箱、脅威度評価、プロシージャルマップ生成器
  - `ai/` : 自律攻略AI（`AutoPlayBot`、経路探索 `AdaptiveNavigator`、幾何連動コンテキスト `TacticalContext`、8歩制御、各Behavior戦術群 `behaviors/`）
  - `simulation/` : ヘッドレスバッチ実行ランナー＆テレメトリ集計基盤
  - `services/` : セーブ管理、ストレージドライバ、マッププリセット＆共有コード管理（`MapPresetManager`）
  - `view/` : Canvasレンダラー、DOM UIマネージャー、インスペクタモーダル、ドット絵描画コード
  - `audio/` : Web Audio API による PSG風シンセサイザー
- `scripts/` : ヘッドレスシミュレーションCLI（`simulate.ts`）および戦略比較評価スクリプト（`evaluate-params.ts`）
- `test/` : ゲームロジック・マップ生成・AI・アーキテクチャ境界の検証用テストスイート（全36スイート）
- `docs/` : 仕様書・設計書・ロードマップ等の技術資料（詳細は [docs/README.md](./docs/README.md) を参照）
