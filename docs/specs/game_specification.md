## 1. 基本概要 (Overview)

- **タイトル**: DS1ish
- **ジャンル**: 2Dトップビュー・アクションパズルRPG (Dragon Slayer-like)
- **視点・スクロール**: 自キャラ中心固定・キャラクタ単位（タイル単位）2Dスクロール
- **ゲーム方式**: 時間制限付きターン制（インジケーター方式。プレイヤーが一定時間内に行動、待機時は自動ターン進行）
- **勝利条件**: マップ内の3つ首ドラゴンを討伐し、出現した**4つのクラウン（王冠）をすべて同時に所持して「我が家（Home）」へ帰還する**。
- **敗北条件**: プレイヤーのHP（生命力）が0になる。

## 2. コアループ & ゲームサイクル (Core Loop)

```
[ダンジョン探索] ────> [宝箱・アイテム回収] ────> [我が家へ帰還]
       │                                              │
       ▼                                              ▼
[敵・壁のパズル対処] <── [魔法/岩でルート開拓] <─── [HP回復・能力強化]
       │
       ▼
[ドラゴン討伐] ────> [王冠4個回収] ────> [我が家へ持ち帰りクリア]
```

1. **序盤**: まずマップ上の「剣」を回収（剣がないと敵にダメージを与えられない）。コインを拾い家に帰ってHP最大値を一時底上げする。
2. **中盤**: 「鍵」を入手して宝箱を開け、「パワーストーン」を家に持ち帰って攻撃力（STRENGTH）を向上。「指輪」でブロックや家を移動させ、モンスターの出現場所（墓）を塞ぎつつ探索範囲を拡大。
3. **終盤**: 経験値蓄積により各種魔法や斜め移動を習得。ドラゴンの守る領域へ侵攻。
4. **決戦・クリア**: ドラゴンの首を討伐 $\to$ 家から大量発生するモンスターや死神を捌きつつ、4つの王冠を回収して我が家へ帰還。

## 3. 画面・表示仕様 (Display & Interface)

### 3.1 画面レイアウト
- **メインビュー（マップ画面）**:
  - タイルベースのグリッド表示。
  - プレイヤーは常に画面中央に固定され、マップが1マス単位でスクロールする。
  - レトロ表示基準: フィールド2色、キャラクター4色のクラシックスタイル。
  - **ピンチ表示**: プレイヤーのHPが500未満になると、画面のパレット（通常緑ベース）が赤色に変化し、危機的状況を警告する。
- **ステータス表示部 (HUD)**:
  - `HITPOINTS` (現在HP)
  - `STRENGTH` (攻撃力)
  - `EXPERIENCE` (経験値 / 帰宅時HP回復上限 / 防御力)
  - `GOLD` (所持コイン数)
  - `MAGIC` (魔法の壺ストック / 魔力)
  - `CROWN` (所持クラウン数: 0〜4)
  - `HOLD ITEM` (現在所持している単一アイテムアイコン: 鍵、十字架、指輪、パワーストーン等)
  - `INDICATOR` (ターンタイマー。人の形などのアイコンが左から右へ進み、右端到達で1ターン経過)

## 4. プレイヤーパラメータ & 成長システム

| パラメータ | 役割・仕様詳細 | 成長・変動契機 |
| :--- | :--- | :--- |
| **HITPOINTS** (HP) | 生命力。0になるとゲームオーバー。 | 敵からの被弾で減少。家に帰ることでEXPERIENCEの値まで全回復する。GOLD所持状態で帰宅すると一時的にEXPERIENCEを超えて上乗せされる。 |
| **STRENGTH** (STR) | 攻撃力。敵への与ダメージに直結する。 | 「パワーストーン」を我が家に持ち帰ることで恒久的に上昇。一部の敵（dora, knight等）に吸い取られると減少。 |
| **EXPERIENCE** (EXP) | **本作を象徴する特徴的仕様**: 単なる経験値ではなく、**「家に帰宅した際に回復できるHPの上限値」**であり、かつ**「敵からの被ダメージを減らす防御力」**となる。また一定値到達で魔法や特技を順次習得する。 | モンスターを撃破することで増加。一部の敵（rich, crownload等）に吸い取られると減少。<br>※注意: EXPがHPを超えると、逃げていた弱敵が一斉に襲いかかってくるリスクがある。 |
| **GOLD** | 所持コイン数。 | マップ上のコインを拾うと増加（スタック可）。我が家に帰還すると、所持数に応じてHPが一時上乗せ加算され、GOLDは0になる。 |
| **MAGIC** | 魔力・魔法使用ストック。 | 「魔法の壺」を拾うと+1。魔法を発動すると消費（一部の魔法を除く）。 |
| **CROWN** | 所持クラウン数。最大4個まで同時所持可能。 | ドラゴン討伐後、出現したクラウンを拾うことで増加。**1個でも所持していると魔法が使用できなくなる**。4個揃えて家に帰るとステージクリア。 |

## 5. アイテム & マップオブジェクト仕様

### 5.1 即時取得アイテム（持ち歩き不可）
- **剣 (Sword)**:
  - 最重要アイテム。未所持状態では敵に一律10ダメージしか与えられず、実質的に戦闘不能。
  - 入手することで初めてSTRENGTHが有効化される。ドラゴンの炎で黒焦げになった際も、再取得で正常状態に戻る。
- **コイン (Coin)**:
  - 我が家に持ち帰ると、EXPERIENCEの上限を超えて一時的にHPを増強できる。
- **魔法の壺 (Potion)**:
  - 拾うと `MAGIC` が1増加。

### 5.2 携帯アイテム（1種類のみ所持可能 / 置き直し可能）
※クラウンのみ別枠管理（複数所持可能）。下記アイテムは1つのみ携帯可能。
- **パワーストーン (Power Stone)**:
  - 我が家に持ち帰ると `STRENGTH` が恒久的に増加する。
  - 通常は宝箱から1/8の確率で出現するが、特定の歩行ルール（後述の8歩周期）で確定出現させられる。
- **十字架 (Cross)**:
  - 所持中は敵から一切の攻撃を受けない（無敵）。ただし自身も攻撃・魔法が不可となる。
  - **結界機能**: 地面に置かれた十字架のマスには**一般モンスター・おばけが進入不可**（結界として機能）。
  - 死神に取り憑かれている時に十字架の上を通過すると、**死神が消滅**する。
  - おばけは地面の十字架を持ち去ることはできないが、プレイヤーが所持している十字架は奪うことができる。
- **鍵 (Key)**:
  - 所持している間、通常の宝箱を開けることができる（ドラゴンの宝箱を除く）。
- **指輪 (Ring)**:
  - 所持している間、進行方向にある「ブロック（壁）」や「我が家」を押して移動させることができる。

### 5.3 マップオブジェクト
- **我が家 (Home)**:
  - 拠点。侵入することでHP全快（EXP基準＋コインボーナス）、パワーストーンによるSTR上昇、クラウン4個所持時のクリア判定が行われる。
  - **絶対安全地帯**: モンスターは家の中に入ることができず、家の外壁の向こうから家の中にいるプレイヤーを攻撃することもできない。
  - 指輪所持時は指輪（RING）で押して動かせる（倉庫番）。ワープゾーンや墓の上に家を押し通しても、家が移動した後に元のワープゾーンや墓は自動復元される。
  - **メインホーム（本物の家）の決定**: 複数存在する場合、**最後に入った、または指輪で押した（利用した）家**が本物（RETURN魔法や死亡時のワープ先、AutoPlayBotの帰還目標）となる。
- **ブロック / 岩 (Block/Wall)**:
  - 通行不可障害物。指輪で押すか、BREAK/KICK魔法で破壊・除去可能。モンスターは通過不可、ゴーストはすり抜ける。生存モンスターがいるマスには重ねて押し出せない（壁埋まり防止）。
- **墓 (Grave)**:
  - モンスターのスポーン地点。墓の上に岩（BLOCK）が乗っている間は次の敵が発生しないため、岩で塞いでスポーンを封じる戦術が攻略の要。
- **宝箱 (Treasure Chest)**:
  - 鍵を所持していると開く。中身は9ターン周期で変化（パワーストーン、コイン、壺、死神など）。
- **ワープゾーン (Warp Zone)**:
  - 別の特定ワープゾーンへと瞬時に転送される（ワープ先は固定ペア）。我が家を押して通過しても下地情報が保護され消滅しない。

## 6. 魔法 & 特技システム

EXPERIENCEが一定値に達するごとに順次アンロックされる。魔法の発動には `MAGIC > 0` が必要（一部例外あり）。
※クラウン所持中、十字架所持中、死神憑依時は使用不可。

| 魔法 / 特技 | 消費MAGIC | 効果詳細 |
| :--- | :---: | :--- |
| **JUMP** | 1 | マップ上を徘徊しているゴースト（おばけ）の中から1体がランダムに選ばれ、その位置へワープする。 |
| **RETURN** | 1 | 本物の「我が家」へ瞬時にテレポートする。 |
| **MAP** | 1 | ダンジョン全体の縮小マップを表示する。家(白)、墓(黄)、ワープ(水色)、宝箱(青)と色分け表示。 |
| **BREAK** | 0 (実質) | 向いている方向の壁・岩を1マス破壊する。※MAGICが1以上必要だが、使用直後に回復するため消費なし。 |
| **KICK** | 0 (実質) | 目の前の岩を進行方向へ蹴り飛ばす。モンスターに衝突した場合は敵を即死させる。空間がない場合はBREAK同様に岩が消滅。 |
| **FREEZE** | 1 | 自キャラ周囲のモンスターを一定時間凍らせ、行動不能にする（ゴースト・ドラゴンには無効）。 |
| **FLASH** | 1 | 画面内のすべてのモンスターを一定時間行動不能にする（無抵抗で攻撃可能）。 |
| **FLY** | 1 | 一定時間、鳥に変身して高速飛行する。壁や敵をすり抜けられ、被ダメージも受けないが無敵中は攻撃不可。ドラゴンの背後や尻尾へ安全に着地する際に重宝する。 |
| **斜め移動 (特技)** | **0** | **厳密には魔法ではなく常時発動特技**。プレイヤーが斜め8方向へ移動・攻撃可能となる。ドラゴンの射程外（斜め）から一方的に首を攻撃するために必須。 |
| **SAVE** | 0〜1 | ゲームの現在状態を保存する。 |

## 7. エネミー & ボス仕様

### 7.1 特殊エネミー
- **ゴースト / おばけ (Ghost)**:
  - HP/攻撃力を持たない。ターン進行に縛られず、リアルタイムで壁を完全に無視して直線飛行し、外壁で反射する。
  - プレイヤーへの直接ダメージはないが、落ちているアイテムを吸い上げて壁の中や遠隔地へポイ捨てする（壁の中に捨てられたアイテムはBREAKやJUMPで回収）。
  - プレイヤーとすれ違った際、手持ちアイテムを強引に強奪する（十字架を含む）。
  - 地面に置かれた十字架上は通過できず、十字架を持ち去ることもできない。
  - プレイヤーの魔法 `JUMP` は、このゴーストの現在位置へワープする魔法として機能する。
- **死神 (Death)**:
  - 宝箱から出現し、プレイヤーに取り憑く。
  - 憑依中は**一切の魔法が使用不可**となる。
  - 十字架の上を通過すると**消滅**する（我が家に帰ることでも引き離し可能）。すでに取り憑かれている時に別の宝箱から死神が出た場合、その場に留まる。

### 7.3 ボス：ドラゴン (Dragon) 仕様
胴体を中心に、3つの頭（左・中央・右）と1つの尻尾が十字状に配置されている固定配置ボス。
周囲4箇所のドラゴンの宝箱（`CHEST_DRAGON`）の上を含む、各首の上下左右4方向隣接マスはドラゴンの直接攻撃範囲（危険地帯）となる。

| 部位 | 生命力 (HP) | 攻撃力 (ATK) | 防御力 (DEF) | 挙動・特性 |
| :--- | :---: | :---: | :---: | :--- |
| **lefthead** (左首) | 650,000 | 600,000 | 300,000 | 正面直線に強力な火炎弾攻撃。上下左右の隣接マス（宝箱上含む）への直接攻撃＆直線攻撃への反撃。斜め方向（死角）からの攻撃には反撃不可。 |
| **centerhead** (中首) | 650,000 | 500,000 | 400,000 | 正面直線に火炎弾攻撃。上下左右の隣接マス（宝箱上含む）への直接攻撃＆直線攻撃への反撃。斜め方向（死角）からの攻撃には反撃不可。 |
| **righthead** (右首) | 650,000 | 500,000 | 380,000 | 正面直線に火炎弾攻撃。上下左右の隣接マス（宝箱上含む）への直接攻撃＆直線攻撃への反撃。斜め方向（死角）からの攻撃には反撃不可。 |
| **body** (胴体) | 655,340 | 0 | 655,350 | 攻撃力0だが防御力が極大。討伐不要（撃破対象外）。通過不可。 |
| **tail** (尻尾) | - | - | - | 徒歩で接触すると初期地点付近へ弾き飛ばされる。戦闘不可。`FLY`の魔法で上空から降りることで弾かれずに着地可能。どの首とも上下左右で隣接していない安全地帯であり、ここから斜め上（`UP_LEFT` / `UP_RIGHT`）で左首・右首をノーダメージで攻撃可能。 |

#### ドラゴンの攻撃範囲と攻略ルール
1. **宝箱上（首の隣接横）の危険性**:
   - ドラゴン周囲4箇所の宝箱マスは首の上下左右4方向に直線隣接しているため、待機中は毎ターン首から直接攻撃を受け、宝箱上から首への攻撃も直線判定となり反撃ダメージを受ける。
2. **死角からの斜め攻撃**:
   - 首の外周斜めマスや、しっぽの上から斜め移動（`UP_LEFT`, `UP_RIGHT`, `DOWN_LEFT`, `DOWN_RIGHT`）で首を攻撃した場合は、死角攻撃となり反撃ダメージを受けない。
3. **しっぽを活用した正規攻略法**:
   - `FLY` でしっぽの上に着地 $\to$ しっぽの上から斜め移動で左首・右首を安全に撃破 $\to$ 破壊した首の死角から中央首を撃破するのが王道ルート。

## 8. 終盤フェーズ詳細ルール & ゲーム進行ロジック

### 8.1 ドラゴン討伐後の変化
1. **首を1本討伐**:
   - **我が家の復活と2軒化**: 指輪で移動させていた我が家はその位置に維持され、**初期位置（`initialHomePos`）に新たな我が家が復活配置**される（マップ上に我が家が2軒となる）。
   - **敵の湧き出し**: 撃破されたモンスターが**初期位置に復活した我が家（`spawnHomePos`）から湧き出す**ようになる（プレイヤーが移動させた安全な別宅からは湧かない）。
2. **首を2本討伐**:
   - 初期位置の我が家からすべてのモンスターが湧き出すようになる。
3. **首をすべて討伐 (3本撃破)**:
   - フィールドの色合いが変化（黒色ベース）。
   - ドラゴンが護っていた特殊宝箱が開き、**4つのクラウン**が出現。おばけによってマップ上に散乱させられる。
   - 従来の墓は残るが、モンスターは湧かなくなる（初期位置の家から湧く）。

### 8.2 王冠（クラウン）所持とクリア条件
- **クラウン回収ルール**:
  - クラウンは4つ同時に所持可能（他アイテム枠とは別）。
  - 1個ずつ家に届けてもカウントされずクリアにならない。**「4つすべて所持した状態」で我が家へ入らなければならない**。
  - クラウンを1個でも所持している間は、全魔法が使用禁止となる。

### 8.3 パワーストーン出現の「8歩周期ルール」
- 宝箱からパワーストーンが出現した直後、**8歩移動してから次の宝箱を開けると確実にパワーストーンが出現する**。
- レベルデザイン上、この仕様を活用して意図的にSTRを高めることが必須テクニックとなっている。
