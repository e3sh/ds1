# DS1ish クリア攻略ガイド・実践戦術まとめ (Clear Strategy Guide)

本書は、『DS1ish』（PC-8801版『ドラゴンスレイヤー Level 2.0』準拠）において、プロシージャル生成された多様なダンジョン（特にインフレが激しい `EXPONENTIAL` モードを含む標準環境）を安定して攻略するための**実践的な攻略セオリーと、実装・検証から得られたクリアへの工夫**を体系的にまとめた資料である。

---

## 1. クリアまでの基本ロードマップ

| フェーズ | 主な目標と優先行動 | 重要なマイルストーン |
| :--- | :--- | :--- |
| **1. 序盤（立ち上げ）** | 剣（`SWORD`）回収 → パワーストーン（`POWER_STONE`）奉納で STR 強化 → 安全な敵狩り・金貨換金・宝箱開錠 | `BREAK` 習得（EXP 4,000）<br>斜め移動解禁（EXP 12,000） |
| **2. 中盤（決戦準備）** | 宝箱・ポーションでの MP 備蓄 → **前線基地移転（デュアルホーム化）** → 防御 EXP 確保・HP オーバーヒール | `RING` による拠点移動<br>王冠用 MP プール確保 |
| **3. 終盤（ドラゴン決戦）** | 斜め安全位置からの 3 首撃破 → 首 1 本撃破後の初期家復活 → 決戦中の退避・最終首前 MP 補給 | 首の DEF を上回る STR<br>最終首前の `MP >= 2` 維持 |
| **4. 王冠脱出** | 周囲の敵無力化（`FREEZE`/`FLASH`）→ 王冠回収 → 近い方の `HOME` へ最短帰還 | `MP >= 2` リザーブ保護<br>2 拠点活用による帰還短縮 |

## 2. 序盤〜中盤の育成・リソース確保の工夫

### 2.1 1枠インベントリ制約と「鍵一時退避スワップ」
* `DS1ish` では手持ち枠（`holdItem`）が 1 つしかなく、**手ぶら（`NONE`）でないと床アイテムを拾えない**（ただし `COIN` / `POTION` / `SWORD` は拾った瞬間に消費・装備され手ぶらのままになる）。
* 宝箱を開けた直後などに鍵（`KEY`）を持ったまま足元の有益アイテム（`POWER_STONE`, `POTION`, `COIN` 等）を回収したい場合は、**隣接する安全な空き床に鍵を一時置き → 足元のアイテムを回収 → 鍵を拾い直す**（`ItemSwapTactics`）ことで、鍵を手放さずにアイテムを回収し続けられる。

### 2.2 8 歩周期による宝箱開錠
* パワーストーンを家に奉納してからの歩数（`stepCountSinceStone`）が 8 歩の周期に合うように、宝箱の手前で安全な隣接ピボット移動を行って歩数を同期させてから開錠する（`EightStepController`）。
* これにより、中盤〜終盤の MP 源となるポーションや追加リソースの獲得効率を高められる。

### 2.3 安全な経験値稼ぎ（`BREAK` / 斜め移動の早期解禁）
* EXP が 4,000 未満で岩を壊せない段階や、12,000 未満で斜め移動ができない段階では、無謀に強敵へ挑まず以下の安全な対象を選んで狩る（`EarlyBreakUnlockMission`）：
  - 一撃撃破（`ONE_SHOT`）可能、または被ダメージが許容範囲内でドレイン能力を持たない敵。
  - `FLASH` で一時停止中、または `FREEZE` で永久凍結中の敵（反撃・逃走を受けずに安全に倒し切れる）。
  - 連続狩りは HP が安全下限（例：`Math.max(300, Math.floor(EXP * 0.5))`）を下回らない範囲に留める。

### 2.4 墓（`GRAVE`）の湧き対策
* 墓は敵のスポーン源となるため、周囲に押し込める岩（`BLOCK`）があり指輪（`RING`）にアクセスできる場合は、墓の周囲や出口を岩で封鎖する（`SealGraveMission`）ことで敵の過剰湧きを抑えられる。

## 3. 決戦準備の核心：デュアルホーム（2拠点化）と前線基地移転

### 3.1 なぜ家を動かすのか？
* ドラゴンの首を 1 本倒すと、マップ上の初期位置（`initialHomePos` / `spawnHomePos`）に家が復活する。
* 決戦前に指輪（`RING`）で現在の家を別の場所へ押して運んでおくと、**「復活した初期の家（敵湧き場兼用）」と「移動させた前線基地（別宅）」の 2 軒の `HOME` がマップ上に併存する**状態になる。
* どちらの家に入っても全回復と王冠の納品が可能であり、王冠はドラゴンと無関係にマップ各地へ出現するため、離れた 2 箇所に拠点を持つことでどの王冠を拾っても帰還距離と道中のリスクを大幅に圧縮できる。

### 3.2 アンカー選定の条件（どこへ運ぶか）
元の家（`spawnHomePos`）の近くに置いても 2 拠点化のメリットが薄いため、**元の家から十分離れたトーラス対角付近**を目標にする（`MapSituationEvaluator.findSafeRelocateAnchorCandidates` / `RelocateHomeMission.selectBestAnchor`）。安全な第 2 拠点として以下の条件を満たす地点を選ぶ：
1. **元の家からの距離**: 十分離れていること（64×64 マップならマンハッタン距離 32 以上を優先目標）。
2. **墓からの安全距離**: すべての墓からチェビシェフ距離で 3 マス以上離れていること（墓湧き敵による包囲を防ぐ）。
3. **ドラゴン回避**: ドラゴン本体および火炎射線上でないこと。
4. **袋小路回避**: 隣接 4 方向のうち、通行不能地形（`WALL_STATIC` / `GRAVE` / `WARP`）でないマスが 2 方向以上あり、出入りが容易であること。
5. **到達可能性の実証**: 候補地点に対して、家の押出経路探索（BFS）が実際に到達可能であること。

### 3.3 迂回経路探索とルート開拓
直線 2 方向だけの単純な押し出しでは、わずかな障害物で 1〜7 マスしか動かず中途半端に終わりやすい。以下のルールで経路探索と開拓を行う：
* **禁止・迂回対象**:
  - `WALL_STATIC`・`GRAVE`・`WARP`・他の `HOME`・ドラゴン部位・開錠不能な宝箱（`CHEST` / `CHEST_DRAGON`）・`DEATH` / `CROWN` は押し出し先として避けて迂回する。
  - プレイヤー自身が**家の背後に回り込めるか**（家を通らずに立ち位置へ移動できるか、曲がり角で裏に回れるか）を判定しながらルートを決定する。
  - **ワープ踏みの防止**: 押す際のプレイヤーの立ち位置（`standPos`）としても `WARP` タイルは避ける。
* **ルート上の障害物開拓（`CLEARING_PATH`）**:
  - **岩（`BLOCK`）**: 押し出し先または立ち位置にある場合は `BREAK`（または `KICK`）で破壊して道を開く。
  - **床アイテム（`COIN`, `POTION` 等）**: 押し出し先に床アイテムがある場合は、手持ちの `RING` を**押出ルート外の安全な空き床**へ一時ドロップして手ぶらになり、アイテムを回収して退かしてから `RING` を拾い直して押し出しを再開する。
* **進捗ベースの継続・中断**:
  - 固定のターン上限（45T 等）で打ち切らず、BFS で到達不能と判明した時、または家・目標への進展が一定ターン連続で完全に停滞した時のみ中断する。

## 4. ドラゴン決戦の工夫（`SlayDragonMission`）

* **斜め安全攻撃（Attack Spot）の徹底**:
  - ドラゴンの火炎弾は直交 4 方向に飛ぶため、EXP 12,000 で斜め移動・斜め攻撃を解禁した後は、**首の斜め隣接マス（火線外）** に陣取って安全に攻撃する。
* **倒せる首から優先撃破**:
  - 首ごとに DEF が異なる場合があるため、現在の STR でダメージが通る首（`player.strength > head.def`）を優先して狙う。
* **決戦中の一時帰還回復**:
  - 決戦中に HP が危機ライン（HP < 35% かつ HP < 20,000）に落ちた場合は、無理に殴り続けず**2 軒の `HOME` のうち近い方**へ一時帰還して全回復する。
* **最後の首を倒す前の MP 補給**:
  - 残り首 1 体となった時点で `MP < 2` の場合は、最後の首を倒して王冠フェーズ（魔法不可・敵再配置）に入る前に、周囲のポーションで MP を補給しておく。

## 5. 王冠脱出フェーズの工夫（`CrownEscapeMission`）

王冠（`CROWN`）を手持ちしている間は**一切の魔法が使えず**、また強敵の攻撃・反撃で即死しやすいため、「王冠を拾う前」と「安全に一時ドロップした瞬間」の魔法・立ち回りが生命線になる。

### 5.1 MP 温存と魔法の優先順位
* **`MP = 1` リザーブ保護**:
  - 緊急時の `RETURN` / `BREAK` 用に最後の 1 MP を温存し、退避不能な隣接即死の危機でない限り `MP <= 1` での `FLASH` 乱発を抑止する。
* **`FLASH` の過剰消費抑制**:
  - 徒歩で回避可能な状況では `FLASH` を撃たず、8 ターンのグローバルクールダウンを設けて連続浪費を防ぐ。
* **`FREEZE` 優先による恒久無力化**:
  - 一時足止めの `FLASH` よりも、永久凍結で脅威を完全排除できる `FREEZE` を優先して帰還ルート上の危険敵を処理する。
  - **例外（`HOME` 近傍）**: `realHomePos`（帰還先）の近く（チェビシェフ距離 2 以内）では、凍結した敵が家の入口を塞いで入れなくなるのを防ぐため、`FREEZE` を抑止して `FLASH` や回避を優先する。
* **敵湧き家（`spawnHomePos`）封鎖バリケード**:
  - プレイヤーが `realHomePos` 付近におらず `spawnHomePos` 付近にいる場合、`spawnHomePos` の周囲にいる敵を `FREEZE` で凍らせて蓋をすることで、後続の敵スポーンを抑制できる。

### 5.2 王冠回収・運搬中の緊急打開
* **拾得前の事前クリア**:
  - 王冠のマスに乗った際、周囲に未凍結の危険敵がいる場合は、王冠を拾う前（手ぶらで魔法が使える状態）に一撃撃破・`FREEZE`・`FLASH` で周囲を無力化してから拾う。
* **運搬中のルート開削（一時ドロップ）**:
  - 帰還経路が岩（`BLOCK`）で塞がれている場合は、安全な床に王冠を一時ドロップして `BREAK` で岩を砕いてから再回収する（`CLEARING_RETURN_BLOCK`）。
* **運搬中の HP 低下と `RETURN` 緊急帰還**:
  - 家まで距離がある（マンハッタン距離 > 8）状態で HP が 35% 未満になり、かつ `MP >= 2` ある場合は、足元が空いている安全な床に王冠を一時ドロップし、`RETURN` で `HOME` へ戻って全回復してから王冠を取りに戻る。
* **致死敵接近時の自殺ドロップ防止**:
  - 王冠運搬中に隣接・接近する危険敵がいる場合、ワンパン可能なら殴って突破し、不可なら無防備なドロップを避けて退避する。安全な空き床で魔法を撃つための一時ドロップは、同一地点での無限ドロップループを防ぐクールダウン（6T）付きで行う。

## 6. 危険回避・移動の基本セオリー（`AdaptiveNavigator` / `TacticalStallResolver`）

* **脅威度に応じた ZOC（接近禁止帯）設定**:
  - 致死級（`LETHAL`）の非凍結敵の周囲 8 マス（隣接）は原則進入禁止とし、チェビシェフ距離 2 の外周にも警戒コストを置いて先手で迂回する。
* **ワープ往復の防止**:
  - ワープを踏んだ直後の一定ターン（12 ターン）はそのワープ元をタブー化し、意図しないループを防ぐ。
* **袋小路・包囲からの脱出優先順位**:
  - 四方を塞がれた場合は、`RETURN` → `JUMP` → `BREAK`（隣接岩破壊）→ `FREEZE` / `FLASH` → 一撃撃破突破（`BUMP`）の順で打開手段を選択する。

## 7. 検証データによる効果の裏付け（EXPONENTIAL 30 ラン）

`STANDARD_ROOMS` / `NORMAL` / `STANDARD` / `maxTurnsLimit = 3000` / `baseSeed = 10000` の 30 ランにて、`CrownEscapeMission` の MP 温存調整に加えて、前線基地移転のルート探索（迂回BFS）・障害物開拓・進捗ベース中断・対角安全アンカー選定を導入した前後の比較結果は以下の通り：

| 指標 | 移転改善前 | 移転改善後 | 変化 |
| :--- | :---: | :---: | :---: |
| **全体勝率** | 60.0% (18/30) | **86.7% (26/30)** | **+26.7 pt** |
| **`MONSTER_ATTACK` 敗北** | 11 件 | **4 件** | -7 件 |
| **`TIMEOUT` 敗北** | 1 件 | **0 件** | -1 件 |
| **`FLASH` 平均使用回数** | 3.30 回 | **2.07 回** | -1.23 回 |
| **`FREEZE` 平均使用回数** | 10.37 回 | **8.63 回** | -1.74 回 |
| **`movedDist === 0`** | 3 件 (勝率 66.7%) | 2 件 (勝率 100.0%) | - |
| **`movedDist 1..7` (中途半端な移転)** | 11 件 (勝率 54.5%) | **1 件** (勝率 0.0%) | -10 件 |
| **`movedDist >= 8` (十分な移転)** | 16 件 (勝率 62.5%) | **27 件 (勝率 88.9%)** | **+11 件** |

この結果から、**「中途半端な 1〜7 マス移転をなくし、障害物を開拓してでも元の家から離れた安全地点（`>= 8` マス以上）へ確実に 2 つ目の拠点を構築すること」**と**「`FLASH` 浪費を抑えた MP 温存」**が勝率向上に大きく寄与していることが確認された。
