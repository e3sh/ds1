## 1. 今回実装・改修された3大機能

### 1.1 交互に戦うバトル調停システム (Turn Combat Arbitration)
- **背景と課題**:
  従来の実装では、プレイヤーが敵に体当たりした同一フレーム内で「プレイヤーの与ダメ」と「敵の反撃被ダメ」が一括同時処理されていました。
- **改修後の仕様 (交互バトル調停ルール)**:
  - **プレイヤーターン（体当たり手番）**:
    - プレイヤーが敵マスに向かって移動した際、敵へのダメージのみを算出・適用します（被ダメは 0）。
    - 敵が生存している場合、プレイヤーはそのマスへ進めず **「押し合い（足踏み）」** となり、ターンを消費します。
    - 攻撃した敵は **交戦相手（`engagedEnemy`）** として捕捉されます。
    - 敵を一撃で撃破した場合は、そのマスへ前進し、交戦状態は解除されます。
  - **敵AIターン（直後の反撃手番）**:
    - プレイヤー行動直後の敵行動フェーズにおいて、交戦中の敵（または隣接する敵）がプレイヤーへ反撃攻撃（`resolveEnemyAttack`）を行います。
    - ここで初めてプレイヤーへの被ダメージが計算・適用され、敵の特殊能力（STR吸収・EXP吸収・壺強奪）が発動します。
    - 画面ログと効果音も、**プレイヤーの攻撃（撃破/命中）** と **敵の反撃（被弾/防御）** が独立して出力されます。

### 1.2 我が家（HOME）帰還処理の完全化と演出
- **背景と課題**:
  家マスに進入した際、内部的な回復処理は行われていたものの、効果音や画面ログ、視覚的フィードバックが不足していました。
- **改修後の仕様**:
  - `Player.healAtHome()` が詳細リザルト `HomeEventResult` を返却：
    - 回復前後のHPおよび回復量
    - 所持コイン（GOLD）の消費枚数と換算HP上乗せボーナス（1枚につきHP+10）
    - パワーストーン所持時の奉納（STR+1,000）
    - 取り憑いていた死神（DEATH）の除霊・浄化
    - 王冠（CROWN）4個奉納時のステージクリア判定
  - **PSG効果音の追加**:
    - `PSGAudio.playHomeHeal()` を新規実装。矩形波による明るく心地よいレトロ上昇アルペジオ（C5 → E5 → G5 → C6）が鳴動。
  - **RETURN魔法との連動**:
    - 魔法「RETURN」で本物の家にテレポートした際も全く同様に完全回復・換算・ジングル・ログが連動。

### 1.3 対峙モンスター情報パネル (TARGET ENEMY)
- **背景と課題**:
  交戦中の敵のパラメータや残りHPがリアルタイムに視認できませんでした。
- **改修後の仕様**:
  - 右側DOM HUDに **「TARGET ENEMY (対峙モンスター)」** パネルを新設。
  - **表示項目**:
    - 種族番号 & 種族名（全32種: NO.01 SKELETON 〜 NO.32 DOPPEL、および3首ドラゴンの各部位）
    - モンスターアバター（属性カラー＋シンボル文字）
    - HPゲージバー（HP割合に応じて緑 → 黄 → 赤にスムーズ遷移）および現在値/最大値
    - ATK（攻撃力） & DEF（防御力）
    - 特殊能力警告バッジ（`⚡ STR吸収`、`🔮 EXP吸収`、`🧪 壺強奪`、`👑 BOSS`）
  - 体当たり時や敵反撃時にリアルタイム同期され、攻撃するたびに敵HPバーがスムーズに減算。
  - 敵を撃破した際、または距離が離脱した際には速やかに「NO TARGET」へと復帰。

## 2. 各ステータスと特殊状態の徹底解説

### 2.1 勇者の基本ステータス (HERO STATUS)

```mermaid
flowchart LR
    SWORD[剣 SWORD] -->|有効化| STR[STRENGTH 攻撃力]
    STONE[パワーストーン] -->|家で換算 +1000| STR
    STR -->|STR - 敵DEF| DMG_OUT[敵への与ダメージ]

    EXP[EXPERIENCE 経験値] -->|敵ATK - EXP| DMG_IN[被ダメージ軽減 (防御力)]
    EXP -->|基準上限| HP[HITPOINTS 体力]
    COIN[所持コイン GOLD] -->|家で換算 1枚=+10HP| HP
    HOME[我が家 HOME] -->|瞬時全快| HP

    CROWN[王冠 CROWNS x4] -->|家に持ち帰る| CLEAR[STAGE CLEAR]
```

| ステータス名 | 意味と役割 | 計算式・詳細ルール |
| :--- | :--- | :--- |
| **HITPOINTS (HP)** | 勇者の生命力。0でゲームオーバー。 | 最大HP = `EXPERIENCE + (所持コイン換算HP)`.<br>家に進入した瞬間に全快する。 |
| **STRENGTH (STR)** | 勇者の腕力。与ダメの基本値。 | パワーストーンを家に持ち帰るごとに +1,000.<br>**【超重要】剣を持たないと攻撃力は10固定。** |
| **EXPERIENCE (EXP)** | 経験値であり、**勇者の防御力そのもの**。 | 被ダメ = `max(0, 敵ATK - EXPERIENCE)`.<br>敵ATKを上回っていれば被ダメは完全0.<br>蓄積量に応じて各種魔法や斜め移動が解禁される。 |
| **GOLD (コイン)** | ダンジョン内で拾った金貨の枚数。 | 手元にストックされ、家に入ると自動換算されて消滅。<br>換算されたコイン1枚につき最大HPが +10 上乗せされる。 |
| **MAGIC (魔法壺)** | 魔法を詠唱するためのストック（MP）。 | 魔法の壺（POTION）を拾うと +1.<br>魔法発動時に消費（BREAKなど一部魔法を除く）。 |
| **CROWNS (王冠)** | 最終勝利条件（4つ集める）。 | 3首ドラゴン討伐で出現する宝箱から入手。<br>4個すべてを我が家へ生還させるとステージクリア。所持中は魔法封印。 |

### 2.2 装備・携帯アイテム・特殊ステータス

| 名称 | 分類 | 効果と仕様 |
| :--- | :--- | :--- |
| **SWORD (剣)** | 恒久装備 | 床に1本のみ存在。拾うと自動装備され、攻撃力が10から本来のSTRENGTHに跳ね上がる。 |
| **RING (指輪)** | 携帯アイテム | 岩（BLOCK）や我が家（HOME）を押して動かせる（倉庫番アクション）。 |
| **KEY (鍵)** | 携帯アイテム | 宝箱（CHEST）をSPACEキーで解錠できる。解錠後も鍵は消費されない。 |
| **CROSS (十字架)** | 携帯アイテム | 被ダメが完全0（無敵）となる。ただし自身も攻撃・魔法が不可。モンスターは十字架を踏めない。 |
| **POWER_STONE** | 携帯アイテム | 我が家へ運ぶとSTR+1,000。 |
| **DEATH CURSED** | 状態異常 | 死神に取り憑かれた状態。魔法が使えなくなる。我が家帰還または十字架マス通過で浄化。 |
| **FLYING** | 特殊状態 | 魔法「FLY」で鳥に変身した状態。外壁以外の障害物・敵を無視して飛行通過できる。 |
| **8-DIR MOVE** | パッシブ特技 | EXP 15,000 で解放。テンキー等で8方向（斜め）移動が可能になる。ドラゴンの首の死角を突ける。 |

### 2.3 モンスター側のステータスと特殊能力

- **HP (Hitpoints)**: モンスターの耐久力。与ダメによって減少し、0になると消滅してEXPを獲得。
- **ATK (Attack)**: モンスターの攻撃力。プレイヤーのEXPとの差額がプレイヤーへの被ダメとなる。
- **DEF (Defence)**: モンスターの防御力。プレイヤー攻撃力から差し引かれる（最低1ダメージ保証）。
- **特殊能力 (Special Abilities)**:
  - `⚡ STR吸収`: dora（NO.09）、knight（NO.13）が所持。反撃時にプレイヤーのSTRENGTHを **3,000** 吸い取る。
  - `🔮 EXP吸収`: rich（NO.10）、crownload（NO.21）が所持。反撃時にプレイヤーのEXPERIENCEを **1,000** 吸い取る（防御力とHP上限が直接削られる）。
  - `🧪 壺強奪`: monstir（NO.05）が所持。反撃時に魔法の壺を **1つ** 奪い取る。

## 3. 戦闘速度（移動頻度）とダメージ計算の真実

### 3.1 敵のスピード（移動頻度）の3段階構造

敵とプレイヤーのスピードは同じではありません。本作では以下のように段階分けされています：

1. **下位モンスター（NO.01〜16: スケルトン〜フラン）: 2ターンに1歩**
   - プレイヤーが2回行動する間に1回しか動きません。
   - 距離を取って逃げたり、障害物を利用して撒くことが可能です。
2. **上位モンスター（NO.17〜32: カンガルー〜ドッペル）: 毎ターン1歩**
   - プレイヤーと同速で毎ターン追跡してきます。
3. **ドラゴンの首討伐後（狂乱加速）: 全敵が毎ターン1歩**
   - 3首ドラゴンの首を1本でも討伐すると、ダンジョン全域のモンスターが激怒し、下位モンスターを含めた全員が毎ターン移動に加速します。
4. **ゴースト（Ghost）: リアルタイム徘徊**
   - ターン制に関係なく、ミリ秒単位の実時間（deltaMs）で壁をすり抜けながら超高速徘徊します。

### 3.2 なぜ序盤は「与ダメ1 / 被ダメ0」になるのか？

最序盤に敵と戦うと「与ダメが1、被ダメが0」になりますが、これは固定されているのではなく、**原作のパラメータ設計による必然** です：

- **プレイヤー与ダメ**:
  $$\text{与ダメ} = \max(1, \text{有効ATK} - \text{敵DEF})$$
  - 初期状態は剣がないため、有効ATKは **10固定**。
  - 最初の敵「スケルトン」のDEFは **150**。
  - `10 - 150 = -140` なので、最低保証値の **1ダメージ** になります。
- **敵反撃被ダメ**:
  $$\text{被ダメ} = \max(0, \text{敵ATK} - \text{勇者EXP})$$
  - スケルトンのATKは **300**。
  - 勇者の初期EXPは **1,000**。
  - `300 - 1000 = -700` なので、被ダメは **0（完全防御）** になります。

### 3.3 ゲーム進行に伴うダイナミックな数値インフレと緊張感

ゲームが進むと、この「1と0の小競り合い」から一変し、**数千〜数十万のダイナミックな数値戦** へと変貌します：

- **剣を拾い、パワーストーンを運んだ場合**:
  - STRが 2,000、5,000、10,000 と上昇。
  - スケルトン（DEF 150, HP 1,500）に対し、`5000 - 150 = 4,850 ダメージ` を叩き出し、一撃必殺で粉砕できるようになります。
- **上位モンスターと遭遇した場合**:
  - NO.03 コンドル: ATK 2,000（初期EXP 1,000だと **1,000被ダメで即死**）
  - NO.09 ドラ: HP 300,000 / ATK 35,000 / **STRを3,000吸収**
  - NO.10 リッチ: HP 100,000 / ATK 45,000 / **EXPを1,000吸収**
  - NO.32 ドッペル: HP 650,000 / ATK 650,000 / DEF 520,000
  - ドラゴンの首: HP 650,000 / ATK 500,000〜600,000 / DEF 300,000〜400,000 / 正面直線火炎弾 & 上下左右隣接マス（宝箱上含む）直接攻撃・反撃（斜め死角攻撃のみ反撃0）
